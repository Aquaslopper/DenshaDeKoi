# Wiki screenshots

These images show the current in-game table, pause menu, and radio panel at
1360 × 768. They were rendered from the game's presentation code with Raylib's
software renderer and a seeded match; the magnification shader was omitted
because the software renderer does not support it. Screenshot orientation and
red/blue channels were corrected after capture. They are useful illustrations,
but are not pixel-identical to a GPU or Windows build.

- `table.jpg`: Controls — field, hands, stock and match HUD.
- `pause.jpg`: Menus & Options — pause menu with the current match HUD behind it.
- `radio.jpg`: Gallery, Radio & Sound — radio controls and station list.

Other useful future captures: dealer selection, match settings, a Koi-Koi / Shobu
decision, the card gallery and 3D viewer, and round/match results. These need
representative game states and visual verification before adding them to the wiki.

## Headless viewer captures

The following ten PNGs were rendered at 1360 × 768 with the adapted
`tools/viewer` software renderer; see its README and `scripts/wiki.txt` for
reproduction and rendering limitations. The options and radio views are opened
from the start menu, not the in-game pause screen.

- `start-menu-1.png` through `start-menu-4.png`: the four start-menu backgrounds.
- `match-settings.png`: match settings.
- `menu-options.png`: options from the start menu.
- `menu-radio.png`: radio from the start menu, powered off.
- `gallery-january.png`, `gallery-august.png`, `gallery-september.png`: card gallery examples.

- `match-card-play.png`: seeded match, immediately after the player drops a matching hand card (generated by `tools/viewer/scripts/match-card-play.txt`; software-rendered, not a desktop recording).
